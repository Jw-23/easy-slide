# 编辑器结构

`App.tsx` 只组织工作区、窗口和全局快捷键。页面导航、画布、属性面板、演示视图、工程菜单和弹窗位于 `src/components/`。通用窗口使用原生 dialog 处理焦点约束、Esc、背景不可交互和关闭后的焦点恢复。

## 文档与操作

- `studio/use-document.ts` 管理草稿恢复、源码编译、当前页和文档历史。DSL 错误保留上次有效预览；草稿允许保存未完成源码。恢复失败不会用示例工程覆盖未读取的旧草稿。
- `studio/history.ts` 的不可变历史包含源码、素材引用和页面位置。连续输入合并为一组；独立操作分组。最多 50 步，按源码和额外图片占用回收较旧记录，始终保留最近一步。历史只在当前会话有效。
- `studio/source-edits.ts` 使用解释器提供的源码范围和词法 token 局部更新字段。标题、备注、过渡、布局与图片插入不再序列化整个工程。复制保留计算表达式并生成新的页面 ID。只有显式「整理」重新序列化文档。
- `studio/use-studio.ts` 封装保存、导入、导出、文件夹和素材操作；同步锁防止重复启动异步任务。任务期间文档只读，仍可浏览页面。素材和导入数据在完整验证后一次提交，撤销时连同图片一起恢复。

## 持久化与导出

`studio/draft-queue.ts` 将 IndexedDB 写入串行化，合并待写的中间版本。仅最新写入可报告保存成功；错误保留在状态栏，可显式重试。页面隐藏时尽快提交，离开仍有未保存编辑的页面时使用浏览器离开提示。浏览器存储失效时仍可导出 ZIP。多标签页的并行写入尚未实现冲突合并。

完整文件夹工程由其清单管理素材，不额外扫描无关文件；纯图片目录扫描限定为 1000 张、总计 200 MB。文件写入失败会中止临时写入。主题、ZIP 与 PPTX 的格式及兼容策略保持不变。

PPTX 模块在导出时加载，代码编辑器在打开 DSL 面板时加载。导出逐页报告进度；Workbox 仍预缓存所有生成的模块，保持离线可用。

## 渲染与布局

`studio/compile-document.ts` 复用未改变的页面和主题对象；`SlideView` 使用 memo 和场景缓存，避免在切换工具、保存状态变化或编辑其他页面时重建全部缩略图。场景几何、主题、动画时间线仍由网页和 PPTX 共用。

工作区面板使用 CSS Grid；桌面支持侧栏收起、分隔线拖动和键盘调整，偏好单独保存在 localStorage。小于等于 900 px 时只显示选中的工作区。画布按容器的可用宽高适配，备注和动画区域独立展开。样式按基础界面、编辑器、动画、弹窗、幻灯片和 PWA 分文件维护。

## 验证

`npm test` 覆盖 DSL、主题、ZIP、PPTX 文件结构、局部源码修改、历史、保存竞态、文件夹限制和演示阶段导航。`npm run build` 同时执行 TypeScript 检查并生成 PWA 资源。

浏览器回归位于 `tests/browser/`，新增工作区检查见 `workspace.spec.ts`；生产缓存与更新检查位于 `tests/pwa/`。只有具备浏览器预览能力的环境才运行这些检查；未运行不能视为通过。重点人工检查分隔线拖动、手机端软键盘、原生菜单、窗口焦点、保存失败重试、PWA 离线动态模块与长文稿流畅度。
